### 🔥 BloggerNepal — Blogging Platform with Docker, Content Recommendation & Analytics

> *"I didn't just build it — I containerized it and shipped it to production."*

A fully-featured blogging platform **BloggerNepal**. This is my most complete project: a real content platform with recommendation, analytics, Cloudinary media, and a live deployment powered by Docker.

| | |
|---|---|
| 🐳 **Dockerized** | Containerized with Docker for consistent dev & production environments |
| ☁️ **Live on Render** | Deployed and running in production — visit it now! |
| 📊 **Analytics** | Post views, likes, and content recommendation built in |

**Key Features:**
- User registration, login, and profile management
- Blog creation with rich content, categories & slug-based URLs
- Content recommendation system
- Post analytics — views and likes tracking
- Featured, Latest, and Popular posts sections
- Categories: Education, Politics, Sports, Psychology & more
- Cloudinary cloud media integration
- Fully responsive design
